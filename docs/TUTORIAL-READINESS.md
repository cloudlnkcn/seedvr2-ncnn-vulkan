# 教程交付核验 · 2026-09-10

> 本页的构建表记录初次教程交付批次；当前数值修复见 [NUMERICS-REPAIR.md](NUMERICS-REPAIR.md)，最新交付缺口见 [CURRENT-GAPS.md](CURRENT-GAPS.md)。历史测试数量不作为当前构建的通过数量。

当前项目可以作为面向有 C++、PyTorch 和基本 Vulkan 经验读者的**进阶移植教程与可执行案例**公开。
它提供从小型真实算子到完整原生应用的学习路线、可复现输入、分项检查和失败记录。
完整课程、跨平台产品及模型画质认证仍有缺项，不能把“教程可用”写成“移植已完美”。

本地验证从锁定归档和宿主 npm 缓存构建，未复用已有原生库或模型包。
第一次构建因会话中断停止；保留主日志，随后复用该次已编译对象完成安装。
这验证了干净源码与本地缓存构建，不是一次全新操作系统安装或全部依赖的重新联网下载。

AWA 参考和导出使用已存在且版本固定的 Python 3.13 / PyTorch 2.9.0+cpu 环境及 pnnx。
本轮重新生成、导出并比较小型案例，没有重新安装该 Python 环境，也没有重跑大模型导出或完整推理。
原生模型计算源码未改变；原有 0.7.0 完整模型证据仍绑定其原始二进制和输入，详见
[历史验证索引](../artifacts/2026-09-08/memory-v1/README.md)。
