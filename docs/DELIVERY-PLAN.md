## 当前交付目标

SeedVR2 **3B** 图片/视频修复，官方固定正向文本条件，单步 CFG=1；输入图片或 SDR 视频，输出 PNG 或 MP4，并保留输入身份、参数、阶段进度和 JSON 报告。使用 Linux x86_64 原生 C++、ncnn CPU/Vulkan，保留本地 Web，增加可安装且与 CLI 共用的 C++ SDK。首批实机为本机 RTX 4060 Laptop 和 CPU；软件 Vulkan 只承担 CI 小型执行，不代表 AMD/Intel 真机验证。

已有范围为图片长边 64..512、视频 1..17 帧/长边 64..128。先保留这些已实现的限制，通过实际资源与完整结果决定扩展，不把官方宣传分辨率当成本机承诺。FP32-B 是显式数学参考；当前 Python 环境为 CPU PyTorch，不能声称运行过官方 CUDA BF16/Apex/FlashAttention 默认路径。官方视频 cache/长片和高分辨率不是当前预览已完成能力。

3. **代码与日常使用**：公共标准 C++ API、CLI/worker、流水线、模型包、图执行各有边界；提供安装 SDK、首次运行帮助、参数/设备预检、Unicode 路径、取消、进度与结果。避免增加无实际需求的插件/调度框架。
4. **真实交付验证**：冻结候选二进制、原生图片与短视频、独立官方参考及新自然内容样例；验证安装搬移、隐藏源码、禁网、外部 C++ 消费。视频功能/逐层数值/内容质量分别记录。
