# 从设计证据到下一项可验收工作

本页把 [设计对照](design-comparison.md) 转成执行顺序。[CURRENT-GAPS](../../CURRENT-GAPS.md) 仍是用户能力与缺口总表；这里给出每一轮需要保留的输入和停止条件。

| 顺序 | 输入和实现 | 本轮完成的定义 | 尚不能推出 |
| --- | --- | --- | --- |
| P0 模型与程序交付 | 审阅过的原模型包、冻结程序、许可证和实际动态库 | 转换包分发清单、损坏/中断检查；在新目录装配并由原生校验；程序安装盘点；托管与干净目标机结果另记 | 本机归档不等于公开下载或跨发行版程序 |
| P1 官方默认参考 | 固定 CUDA BF16/Apex/FlashAttention 环境、相同输入与噪声 | 保存官方输入、输出、环境和失败；以 FP32-B 桥接定位差异 | 官方输出产生不等于低精度原生运行已通过 |
| P2 VAE query 分块 | 当前通过组件、完整 K/V、可调 Q 批大小 | 对同输入逐张量检查、测量峰值和耗时；默认状态与回退明确 | 不自动解锁长视频 |
| P3 时间状态与长片范围 | VAE 因果边界、DiT 上下文、首尾和切镜输入 | 先整段/分段组件一致性，再有限长片的时序及质量协议 | 不预先承诺无限长度或任意分辨率 |
| 按测量调度优化 | load / upload / compute / download 分项、冷暖缓存和峰值 | 控制变量的正确性、收益、代价、默认状态与撤回条件 | 不以另一个项目/设备的速度作为本机收益 |

P0 的本轮输出见 [交付记录](delivery-2026-09-13.md)。P1–P3 仍为待执行工作，不因写入计划而标记实现。画质样本来源不足和 bicubic 负结果保留，扩大范围前必须设计新的任务质量验证。

已有六条大模型数值轨迹在模型数学和执行代码未改变时沿用。安装工具用小型破坏性样例验证拒绝行为，再用一个真实固定输入验证组装路径，避免无理由重复完整实验矩阵。
